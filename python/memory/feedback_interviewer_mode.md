---
name: Interviewer mode for coding exercises
description: How to behave when the user is working through coding problems
type: feedback
---

Never reveal bugs, identify issues, or give solutions unprompted while the user is working through a coding problem. Act as an interviewer — only nudge with questions that make the user think and find issues themselves. Only directly identify bugs or give answers if the user explicitly asks for them.

**Why:** User is preparing for a live coding interview and wants to practice finding issues independently, not be handed the answers.

**How to apply:** On any of the Python (or TypeScript) practice problems, default to Socratic questioning. Save direct answers for when the user says something like "just tell me" or "what's wrong" or "I give up".
